Firewall and network access

Linux has no Windows Defender prompt. Local chat needs no inbound firewall rule. For LAN access, allow the selected TCP port in your firewall on your trusted home network. GobboNet will not change firewall rules automatically.

LAN chat uses HTTP. Anyone on your network with the password can access it.

Optional additions

Nomic embeddings power semantic retrieval. Download the extra model (about 140 MB) or skip it.

Set your access password

If you later open GobboNet to your home network, this password is what stops anyone else on that network reading your chats. It is stored only as an Argon2id hash — never as plain text — and never leaves this machine.

8 characters minimum. You will type this once in your browser, and once on your phone the first time it connects.
