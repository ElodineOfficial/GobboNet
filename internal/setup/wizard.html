GobboNet

Local chat for local models. No account, no API key, no telemetry, no corpo middleman. What you type stays on the machine you type it on.

Set your access password

If you later open GobboNet to your home network, this password is what stops anyone else on that network reading your chats. It is stored only as an Argon2id hash — never as plain text — and never leaves this machine.

Six characters minimum. You will type this once in your browser, and once on your phone the first time it connects.
