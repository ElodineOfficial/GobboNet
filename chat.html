ABOUT


      

        
GOBBONET

        
LOCAL AI TERMINAL // llama.cpp

        
A self-hosted chat workbench for any local GGUF model — characters, memory, branching, retrieval and deep sampler control, all running on hardware you own.

      


      


        
        

          
ⓘ THIS BUILD

          
          

            
Version…

          

          

          
        


        

          
🔒 PRIVATE BY DESIGN

          
No accounts, no telemetry, no cloud round-trips. Two downloads get you set up — llama.cpp and whichever model you pick — and after that you can unplug the internet and it keeps working. The only network calls left are ones you ask for: the optional web-search proxy, and reaching the chat from another device on your own network.

        


        

          
⚙ WHAT'S INSIDE

          

            
💬 Conversations — branch & fork any message into parallel timelines, reroll replies and step back through every variant, follow the model's reasoning in collapsible chain-of-thought, attach files, and schedule prompts to fire on their own.

            
🎭 Characters & memory — build character cards or import them from SillyTavern / TavernAI (V1–V3), swap personas per chat, and keep long stories coherent with a running plot log that records one short beat per compression pass. Open it any time to see exactly what was recorded and when.

            
🔍 Retrieval — give a character a storybook of entities and lore, and the right entry is pulled in when it becomes relevant — by weighted tags, and by meaning via a local embedding model, so a mention that never uses your exact keyword still finds it.

            
🎛 Fine control — per-character samplers (temperature, min-p, top-p, repeat penalty, XTC, DRY), logit bias to nudge or ban specific tokens, carousel system prompts, and {{macros}} that expand before they reach the model.

            
🧩 Extend & own it — attach JavaScript to a single character to give it behaviour of its own, inject site-wide CSS and JS, hot-swap models without restarting, reach it from any device on your LAN behind a password, and export everything as portable JSON.

          

        


        

          
📚 STACK

          

            
Model — Local GGUF (detecting...)

            
Runtime — llama.cpp — runs any GGUF; CUDA/Vulkan/CPU

            
Frontend — Vanilla HTML/CSS/JS — no build step, no frameworks

            
Server — gobbonet — a single Go binary that serves this page and supervises llama.cpp

            
Storage — your browser, mirrored to a state file in the install folder so a reload never loses a thread

            
Licence — AGPLv3 — every file in the install folder is readable and yours to change, and anyone you serve it to gets that same right

          

        


        

          
🗑 YOUR DATA

          
Chats live in two places: this browser's storage for the address you opened, and a state file in the install folder. Uninstalling removes the state file. The browser copy is the browser's — clear it from site settings for the address you use, and do it for each one, since a phone on your LAN keeps its own.
